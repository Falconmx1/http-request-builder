# Changelog

Todas las mejoras y cambios notables en este proyecto serán documentados aquí.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-02

### Añadido
- Lanzamiento inicial de HTTP Request Builder
- Soporte para métodos HTTP: GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS
- Envío de datos en JSON o texto plano
- Cabeceras personalizadas
- Colores en la salida de terminal
- Guardado de respuestas en archivos (JSON, TXT, HTML)
- Archivos de configuración en JSON
- Tiempo de espera configurable
- Verificación SSL desactivable
- Modo verbose para respuestas completas
- Códigos de salida para scripting

### Estructura
- Código organizado en módulos core, cli y utils
- Tests básicos incluidos
- Ejemplos de uso

- Inicialización del repositorio
