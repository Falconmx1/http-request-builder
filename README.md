# HTTP Request Builder

Herramienta CLI para probar, depurar y monitorear APIs REST desde la línea de comandos.

## 🚀 Características
- Pruebas automatizadas de endpoints REST
- Depuración de servicios web
- Verificación de conectividad
- Monitoreo de disponibilidad
- Análisis detallado de respuestas HTTP
- Scripting para integración continua
- Simulación de peticiones HTTP
